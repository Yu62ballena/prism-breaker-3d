# PRISM BREAKER 3D — Hyper Chain-Smash Arena

Three.js（WebGL + `UnrealBloomPass` + カスタムGLSLシェーダー + `InstancedMesh`）をフル活用した、ハイスピード3Dダッシュ撃破・連鎖アクションゲーム。
ゲーム心理学に基づく「中毒性設計」を徹底的に組み込み、思わず「もう1回！」と指が動く体験を目指しました。

🌐 **プレイURL（GitHub Pages）**: https://yu62ballena.github.io/prism-breaker-3d/

---

## 🎮 操作方法

- **移動**: `WASD` / `↑↓←→`（射撃はオートエイム＆オート発射）
- **ダッシュ撃破（DASH-SMASH）**: `SPACE` または `左クリック`
  - 無敵状態で突進し、敵を粉砕！**ダッシュで敵を倒すとクールタイムが即座に0になり、連続ダッシュ連鎖が可能**
- **ノヴァ解放（OVERDRIVE NOVA）**: `SHIFT` / `E` / `右クリック`（OVERDRIVEゲージ50%以上）
  - 周囲の敵弾をすべてクリスタルに変えつつ超高火力ショックウェーブを発生
- **レベルアップ選択**: クリック または `1` `2` `3` キー
- **即リトライ**: リザルト画面で `SPACE` / `R` / `ENTER`（0.1秒で即再出撃）
- **ポーズ**: `ESC`
- ※ スマホ・タブレット向けにタッチ操作（バーチャルスティック＋DASH/NOVAボタン）にも対応

## 🧠 組み込んだ「中毒性」の仕掛け（調査ベース）

| 心理メカニズム | ゲーム内での実装 |
|---|---|
| **タイトなコアループ** | オート射撃で認知負荷を下げつつ、「ダッシュ撃破 → 即クール解消 → 連鎖爆発 → 磁気クリスタル回収」の超高速ループを構築 |
| **極限の Game Juice** | 35〜110ms のヒットストップ、Trauma 曲線による3Dカメラシェイク、動的FOVキック、最大900個の物理バウンド3Dボクセル破片、衝撃波が走るカスタムGLSLフロア、ペンタトニック音階で上昇する手続き型Web Audioサウンド |
| **コンボ倍率＆フィーバー** | 連鎖数に応じてBGMテンポと音階・カメラ・照明が加速。ゲージ100%で虹色ハイスピード状態「FEVER OVERDRIVE」へ自動突入 |
| **変動報酬（Variable Rewards）** | レベルアップ時の3択カードに **COMMON / RARE / EPIC / MYTHIC★** のレア度抽選を導入。さらに不定期に**黄金ジャックポット・メテオ**が出現 |
| **ニアミス＆カスリ（GRAZE）** | 敵弾スレスレを回避すると `✨ GRAZE!` が発動しスコア・フィーバー・ダッシュ短縮を獲得。ゲームオーバー時には「新記録 / 次ランクまであと〇〇点」を表示して闘争心を刺激 |
| **ゼロ摩擦・即リトライ** | ロード画面ゼロ、`SPACE` / `R` 一発で0.1秒再出撃しフロー状態を途切れさせない |
| **メタ進行＆ツァイガルニック効果** | 失敗しても毎回 **CORE SHARDS（◆）** を獲得し、**CORE LAB** で恒久強化・3D機体スキン解放・ミッション報酬へ繋げる。「次の強化まであと〇〇%」の進捗バーで未完了のワクワクを維持 |

## 🛠️ 技術スタック

- **Three.js**（`EffectComposer` / `UnrealBloomPass` / Custom GLSL `ShaderMaterial` / `InstancedMesh`）

- **Web Audio API**（外部音声ファイル不要・完全手続き型シンセBGM＆SE）
- **localStorage**（ハイスコア・恒久強化・スキン・ミッション永続化）
